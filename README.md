# Employee Management System

An interactive and responsive **Employee Management System** built using HTML, CSS, and JavaScript. This project demonstrates how employees can be managed through a simple dashboard.

## Live Demo

**Website:** https://harsht-0206.github.io/employee-management-demo/


## Features

- Dashboard with employee statistics
- Add new employee records
- Edit existing employee details
- Delete employee records
- Search employees by name or other details
- Filter employees by status
- View department information
- Responsive interface for desktop and mobile
- Save data in the browser using LocalStorage

## Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Interactive functionality
- LocalStorage — Browser-based data storage
- GitHub Pages — Website hosting

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the employee management dashboard.

For the best development experience, you can open the folder in Visual Studio Code and use the Live Server extension.

## How to Use

1. Open the dashboard.
2. Add an employee using the available form.
3. Search for employees using the search field.
4. Filter employees by their status.
5. Edit employee information when required.
6. Delete an employee record when needed.

## Data Storage

This project uses the browser's LocalStorage to save employee records.

**Note:** Data is stored locally in the browser and is not shared between different users or devices. Clearing the browser's site data may remove saved records.
